Cardinal WebMCP

Patch a modular synth in your browser. Start with an eight-step FM bass loop or open the rack and build your own.

Play the FM starter Open Cardinal

Allow time for the first load, then click the rack once to start audio. The RUN button on SEQ3 pauses or resumes the starter loop.

Patch with an agent

  1. In Chrome, open chrome://flags/#enable-webmcp-testing, enable WebMCP for testing, and relaunch.
  2. Open the rack in Chrome with a WebMCP-capable agent or the Model Context Tool Inspector.
  3. Run cardinal_patch with {} to check the connection, or ask your agent to inspect the rack and turn up the FM on the second oscillator.

You can patch by hand in Cardinal. To keep your work, use File → Save and download uncompressed and keep the .vcv file.
